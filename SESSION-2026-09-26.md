- Added customer login/signup (`/account/login`, `/account`) with salted-hash + signed-cookie sessions.
- Checkout auto-fills contact details for a signed-in customer.

## Festival hero takeover system
- Replaced the old badge+particle-only festive dressing with a single config file, `src/lib/festivals.ts` — one entry per festival (Ramadan, Eid, Onam, Diwali, Christmas) covering badge text, headline, sub-copy, CTAs, an offer strip, featured product slugs, and a bespoke SVG decoration (`src/components/home/festival-decorations.tsx`).
- Auto-activates by date if the admin has left the theme on "everyday" (only Christmas has a real date range pre-filled — Ramadan/Eid/Onam shift yearly on the Gregorian calendar, so those need that year's real dates added manually); otherwise the admin's Settings → theme choice always wins.
- `?theme=<id>` on the homepage previews a festival's copy/layout for testing (colors don't change in preview — only a real theme switch changes those).
- Fixed: background photo's baked-in label text bleeding through the hero collage (now blurred), and low-contrast headline/CTA text on light themes.
- **To add a new festival later**: add one entry to `FESTIVALS` in `src/lib/festivals.ts`; add a decoration component to `festival-decorations.tsx` only if you want bespoke art.

## Checkout changes
- Removed GST from all totals (cart, checkout, order confirmation, admin orders) — `GST_RATE` is now `0` in `src/lib/format.ts`.
- Removed the "Demo checkout · no real payment" footer line.
- **New-signup discount (WELCOME10, 10% off first order)**: auto-applies for an eligible signed-in customer at checkout. Eligibility is tracked by *both* email and phone at signup (a claimed-offers ledger on the store) so one person can't re-claim it with a second account using a different email but the same phone, or vice versa. Enforced server-side in `createOrder` — never trusted from the client.
- **Checkout now hands off to WhatsApp instead of online payment**: UPI/Card/Wallet are disabled ("Coming soon"); the "Order via WhatsApp" button opens a wa.me chat to the shop's number with the full order (items, totals, delivery address) pre-filled as the message. No order is created in the database automatically — the admin logs it via "Log WhatsApp order" once the customer confirms in chat, same as any other WhatsApp order.
